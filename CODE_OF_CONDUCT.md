# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and help create a welcoming
environment for people of all backgrounds and experience levels. Harassment, insults and
personal attacks are not tolerated.

Please report unacceptable behaviour to the maintainer via
[GitHub](https://github.com/alexanderKuehling). All reports will be handled confidentially.
