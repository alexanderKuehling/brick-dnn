Snap layers together on a canvas, see the shape of every tensor while you build, and export a
clean, runnable PyTorch script. Everything runs in your browser.

This demo has two limits:

- **No training.** To train networks on your own machine (CUDA, Apple GPU or CPU), run Brick DNN
  locally.
- **No accounts.** Save your network with *File → Save as JSON file* instead. Your current
  network is also kept in your browser.

Source code, documentation and local setup: **[github.com/alexanderKuehling/brick-dnn](https://github.com/alexanderKuehling/brick-dnn)**
